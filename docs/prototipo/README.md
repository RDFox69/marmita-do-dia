# Protótipo navegável

A aplicação do repositório é o protótipo funcional para as sessões de teste. Não é uma simulação estática: registra e mantém pedidos no navegador, permite avançar pedidos na fila e altera os resumos ao marcar pagamentos.

## Preparar uma sessão

1. Instale Node.js 20.19+ ou 22.12+ e dependências (`npm install`).
2. Inicie o protótipo com `npm run dev` e abra a URL local apresentada.
3. Prefira uma sessão nova do navegador para começar sem dados de outras pessoas; o botão de limpar dados do navegador remove todos os pedidos e não deve ser usado sem autorização.
4. Explique que o protótipo não envia mensagens pelo WhatsApp, não sincroniza entre aparelhos e usa dados fictícios apenas se a pessoa decidir inseri-los durante o exercício.
5. Leia o roteiro em [`../testes-usuarios.md`](../testes-usuarios.md) e peça consentimento antes de anotar observações.

As atividades e os resultados observados ainda precisam ser coletados. Não atribua a participantes as tarefas de preparação descritas aqui.
